## 1. TONE

**Voice Attributes:**
- **Competent, not condescending** — We know the tech deeply but don't gatekeep
- **Direct, not dry** — Clear communication without corporate fluff
- **Confident, not arrogant** — We deliver, we don't brag
- **Technical, not tortured** — Precise without being pedantic
- **Partner, not vendor** — We're in this together

**Tone Dial:**
| Context | Tone |
|---------|------|
| Documentation | Precise, instructional, accessible |
| Marketing | Bold, benefit-forward, slightly irreverent |
| Support | Patient, solution-oriented, human |
| Crisis | Calm, factual, reassuring |
| Social | Witty, sharp, community-first |

## 2. COLORS

**Primary Palette:**
```
--xmv-deep:     #0D0D0D    (Void black - backgrounds, depth)
--xmv-void:     #141414    (Soft black - cards, containers)
--xmv-electric: #00F0FF    (Cyan pulse - accents, CTAs, energy)
--xmv-amber:    #FF6B00    (Warm signal - alerts, highlights, humanity)
```

**Secondary Palette:**
```
--xmv-slate:    #2A2A2A    (Structure - borders, dividers)
--xmv-ghost:    #6B6B6B    (Muted - secondary text, hints)
--xmv-mist:     #E5E5E5    (Light - primary text on dark)
--xmv-pure:     #FFFFFF    (Maximum contrast - critical text)
```

**Usage Rules:**
- **80/15/5 rule**: 80% void/deep, 15% electric, 5% amber
- Electric NEVER on white backgrounds (eye strain)
- Amber for human touchpoints, errors, warm moments
- No gradients on text (accessibility)

## 3. LOGO

**Wordmark:** XmetaV
- **X** — The intersection, the cross-chain bridge, the multiplier
- **metaV** — Meta-verse operations, autonomous loops
- **V** — Victory, vaults, value, velocity

**Logo Variants:**
- **Primary**: Wordmark + icon (chain-link agent head)
- **Compact**: Icon only (squared, favicon, avatars)
- **Wordmark**: Text only (headers, documents)
- **Reversed**: White on dark backgrounds

**Clearspace:** Minimum 1x the height of the "X" on all sides

**Never:**
- Stretch or distort
- Change colors outside palette
- Add effects (shadows, glows, gradients)
- Use on busy backgrounds without contrast buffer

## 4. TYPOGRAPHY

**Primary: Inter** (Google Fonts)
- Weights: 400 (Regular), 500 (Medium), 600 (SemiBold), 700 (Bold)
- Use: UI, body text, documentation, most content
- Why: Highly legible, technical credibility, open source

**Monospace: JetBrains Mono**
- Use: Code blocks, API responses, technical specs, logs
- Why: Developer credibility, clear distinction from prose

**Display: Space Grotesk** (sparingly)
- Weights: 500, 700
- Use: Large headers, hero text, marketing moments
- Why: Slight technical edge without being gimmicky

**Type Scale:**
```
Hero:     48px/1.1  Space Grotesk 700
H1:       36px/1.2  Inter 600
H2:       28px/1.3  Inter 600
H3:       22px/1.4  Inter 500
Body:     16px/1.6  Inter 400
Small:    14px/1.5  Inter 400
Caption:  12px/1.4  Inter 400
Code:     14px/1.6  JetBrains Mono 400
```

## 5. LOOK & FEEL

**Visual Personality:**
- **Dark mode first** — We live in terminals and dashboards
- **Data as aesthetic** — Charts, logs, agent flows as visual texture
- **Sparse, not empty** — Every element earns its place
- **Motion with purpose** — Micro-interactions, not spectacle
- **Modular blocks** — Clear hierarchy, scannable at glance

**Imagery Style:**
- Abstract node networks (not literal robots)
- Terminal/command line aesthetics
- Flow diagrams and system architecture
- Dark photography with electric accents
- NO: Stock photos of people shaking hands, generic "AI" brains

**UI Patterns:**
- Rounded corners: 4px (tight), 8px (cards), 16px (containers)
- Borders: 1px solid --xmv-slate
- Shadows: Subtle, directional (light source top-left)
- States: Electric for active, amber for attention

## 7. WORDS TO NEVER USE

**Banned Terms:**
- ~~AI~~ → Use "agent" or "autonomous system"
- ~~Blockchain~~ → Use "on-chain" or specific chain names
- ~~Web3~~ → Too vague, say what you mean
- ~~Crypto~~ → Use specific tokens or "on-chain"
- ~~Revolutionary~~ → Show, don't tell
- ~~Disruptive~~ → Overused, meaningless
- ~~Synergy~~ → Corporate nonsense
- ~~Leverage~~ (as verb) → Use "use"
- ~~Scalable~~ → Show scale metrics instead
- ~~Seamless~~ → Nothing is seamless, be honest
- ~~Ecosystem~~ (alone) → Specify what you mean
- ~~Decentralized~~ (as feature) → Only use when technically accurate
- ~~Trustless~~ → Users still trust code, be precise

**Phrases to Avoid:**
- "In the world of..." → Weak opener
- "We're excited to announce..." → Get to the point
- "We're thrilled..." → Corporate enthusiasm
- "Best-in-class" → Prove it with data
- "Future of..." → Present tense only
- "Game-changing" → Games aren't changing, products do

**Tone Violations:**
- No emojis in serious documentation (✅ fine in social/DMs)
- No ALL CAPS for emphasis (use weight, color, structure)
- No exclamation points in error messages
- No "please" in command/CTA buttons ("Submit" not "Please submit")
